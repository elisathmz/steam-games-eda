# Steam Games Data Analysis (EDA)

A Python-based Exploratory Data Analysis (EDA) project focusing on a dataset of Steam games. It covers data cleaning, feature engineering, and visualization to identify trends in release years, pricing, and free-to-play distribution.

## Tech Stack
- Python 3
- Pandas (Data manipulation, cleaning, and missing value imputation)
- Matplotlib & Seaborn (Statistical data visualization)

## Project Structure
- `data_cleaning.ipynb`: Notebook containing the data cleaning and transformation logic.
- `visualizations.ipynb`: Notebook containing the exploratory data analysis and charts.
- `requirements.txt`: Project dependencies.

2. Ensure you have Python installed.
